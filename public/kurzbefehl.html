Sanftwort direkt aus WhatsApp

Mit einem iPhone-Kurzbefehl brauchst du die Webseite nicht mehr aufzurufen: Nachricht markieren → Teilen → Sanftwort. Die ruhige Antwort liegt danach in deiner Zwischenablage, du fügst sie einfach ein.

Einrichtung einmalig, ca. 3 Minuten. Danach geht es in 5 Sekunden.

1. Kurzbefehl anlegen

  1. Öffne die App Kurzbefehle → + (oben rechts). Nenne ihn Sanftwort.
  2. Tippe unten auf das (i) bzw. „Details“ → Im Share-Sheet anzeigen einschalten. Bei „Empfängt“ nur Text auswählen. Bei „Wenn keine Eingabe“: Zwischenablage abrufen.
  3. Aktion hinzufügen: Inhalte von URL abrufen.
    • URL: https://sanftwort.netlify.app/api/kurzbefehl?modus=eingang&nur=text
    • Auf den Pfeil tippen → Methode: POST
    • Anfragetext: Datei → als Datei Kurzbefehleingabe wählen
    • Nur wenn du Plus oder einen Pass hast: Header hinzufügen, Schlüssel x-sw-token, Wert = dein Zugangscode (der Teil ab cs_ in deinem Zugangslink)
  4. Aktion hinzufügen: In Zwischenablage kopieren.
  5. Aktion hinzufügen: Ergebnis anzeigen (oder „Mitteilung anzeigen“).

2. Benutzen

  1. In WhatsApp die Nachricht lange drücken → Kopieren, oder Text markieren → Teilen → Sanftwort.
  2. Ohne Teilen-Menü: Kurzbefehl einfach antippen – er nimmt den kopierten Text aus der Zwischenablage.
  3. Zurück in den Chat, ins Eingabefeld tippen → Einsetzen. Lesen, anpassen, senden.

3. Noch schneller: zweimal hinten aufs iPhone tippen

Einstellungen → Bedienungshilfen → Tippen → Auf Rückseite tippen → Doppeltippen → Sanftwort. Dann reicht: Nachricht kopieren, zweimal hinten aufs iPhone tippen, einfügen.

Selbst schreiben statt antworten?

Leg einen zweiten Kurzbefehl „Sanft schreiben“ an, genauso, nur mit dieser URL: https://sanftwort.netlify.app/api/kurzbefehl?modus=senden&nur=text. Dann tippst du deine wütende Nachricht wie gewohnt, kopierst sie, und bekommst die faire Version zurück.

Datenschutz: Der Text wird nur zum Umformulieren übertragen und nicht gespeichert. Ohne Zugangscode gelten die 3 Gratis-Übersetzungen pro Woche.
